# Лабораторна робота №3
## Модульна структура Flask. Blueprints

### Мета роботи
Удосконалити вебзастосунок на Flask шляхом розділення функціональності на окремі модулі за допомогою Blueprints, використання шаблонів Jinja2 та автоматизованого тестування.

### Виконані завдання

1. Реорганізовано структуру Flask-застосунку.
2. Створено базовий шаблон `base.html` зі спільною навігацією.
3. Реалізовано Blueprint `users` для відображення привітань та сторінки адміністратора.
4. Реалізовано перенаправлення між маршрутами.
5. Створено Blueprint `products` для відображення списку товарів і детальної інформації про кожен товар.
6. Додано обробку помилки 404 для товару, якого не існує.
7. Створено автоматизовані тести за допомогою `unittest`.

### Використані технології

- Python
- Flask
- Flask Blueprints
- Jinja2
- HTML та CSS
- Bootstrap 5
- unittest

### Запуск проєкту

1. Встановити залежності:

   ```bash
   pip install -r requirements.txt
   ```

2. Запустити застосунок:

   ```bash
   python run.py
   ```

3. Відкрити в браузері `http://127.0.0.1:5000/`.

### Запуск тестів

```bash
python -m unittest discover -s tests -v
```
